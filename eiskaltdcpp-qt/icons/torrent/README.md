# Torrent Icon

Original generated piece-ring artwork selected for the Torrent UI in September
2026. `torrent.png` is the full-resolution transparent PNG; Qt scales it for the
toolbar, menu, Preferences entry, and Torrent window.

The icon is compiled into Torrent-enabled applications at
`:/torrent/torrent.png`, independently of the installed icon theme. DC-only
builds do not include this resource.
