# Contour Icon Theme

Scalable icons derived from Phosphor Icons, @phosphor-icons/core 2.1.1.
Copyright (c) 2023 Phosphor Icons. Licensed under the MIT License; the
complete upstream notice is included in LICENSE beside this file.

Upstream: https://github.com/phosphor-icons/core

Theme adaptations: colors, material shading, component positioning, and
compositions of official Phosphor paths. Light 12-unit outline geometry, slate with restrained teal and semantic accents.

Root SVGs target light surfaces; dark/ contains the same filenames for
dark surfaces. The upstream license applies to both sets. Retain LICENSE
when redistributing this theme, including in binary packages.

Reproducible source: tools/icon-themes/ in the EiskaltDC++ source tree.
