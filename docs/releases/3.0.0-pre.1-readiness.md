# 3.0.0-pre.1 Release Qualification

Checkpoint: 2026-10-16. Application source: `c40689d43`; macOS build `30000001`.

Published as a [GitHub prerelease](https://github.com/Delitants/eiskaltdcpp/releases/tag/v3.0.0-pre.1),
not the latest stable release. All eight uploaded asset sizes and SHA-256
digests matched locally. Both public ZIPs and the manifest were downloaded
anonymously and compared byte-for-byte. Signed feeds were published last, then
downloaded from both compiled-in URLs and independently verified against the
application's pinned Ed25519 key and public archive bytes.

## Release Profiles

- Intel x86_64 only, macOS 14 or newer.
- Apple Silicon arm64 only, macOS 26 or newer.
- Both enable the native updater, signed-feed metadata and packaged Sparkle.
- Ad-hoc app signatures; **not Developer ID signed and not notarized**.
  Sparkle archive/feed authentication is separate from Apple notarization.

## Verified

- Both complete application builds and core, Torrent, Qt, settings and window
  suites pass. Eight suite invocations per CPU cover 1,973 cases each, including
  injected publisher allocation, proxy worker-launch and settings-retirement
  failures. ARM: 211,163 assertions. Intel/Rosetta: 210,951 assertions.
- Separate real-GOST interoperability: eight cases / 448 assertions per CPU,
  with no skipped cases, using disposable local identities and servers.
- Full-application disposable updater fixtures: five scenarios per CPU cover
  committed normal quit, canceled quit, forced precommit exit, native terminate
  and canceled native terminate. Exact signed replacement/no-replacement,
  no unwanted relaunch, persisted snapshots and protected data were checked.
- Both current-code live routing helpers verify Cloudflare and Google DoH
  through the configured GOST route with direct traffic denied.
- Both actual bundled applications launch and report the release version,
  with network denied and disposable profiles, without provider overrides.
- Dependency code/data comparisons cover 88 ARM and 44 Intel non-main Mach-O
  images. Component notices are hash-checked. Current selected-recheck ABI 2
  sources accompany the retained dependency sources and build recipes.
- Packaging regression tests: 30 passed. Signed-feed tests: 13 passed.
  Updater fixture-admission tests: 10 passed.

## Limits And Retained Failures

Testing ran on macOS 27.0, with Intel execution under Rosetta. Minimum OS
metadata is checked for every bundled Mach-O image, but physical Intel and
native macOS 14/26 runtime testing are not established. Native-speaker review
of translations and wider Windows/Linux testing remain future work.

Whole-archive bit-for-bit dependency reproducibility is not claimed. The private
OpenSSL qualification framework is excluded from the application; no VM gate
was required. Local QA fixtures and credentials are not release contents.

The initial nested source-patch application silently skipped files; those
builds were rejected. Corrected files were compared before both accepted
builds. Two full-app fixture launches selected an external unpatched libtorrent
before main; those failures are retained. Corrected fixtures explicitly bind
the verified provider. Bundle CLI startup separately checks the packaged
closure. An offscreen CLI attempt was rejected because release bundles ship
Cocoa, not the offscreen test plugin; the Cocoa launch checks pass.

Local evidence: `Work/qa/release-build-20261016/` (not published).
Final ZIP extraction/signature readback, production update signatures and
public GitHub asset/feed readback passed. The hosted wiki was subsequently
initialized and its user documentation synchronized from `docs/wiki`.
Unrelated untracked files were not
committed or uploaded, and the installed app and live profile were not changed.
