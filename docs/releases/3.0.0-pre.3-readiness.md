## Included Changes

- Compact native layout, complete toolbar captions and a separate default
  Superdesign icon theme, with existing icon families preserved.
- Consolidated global, Torrent-only and hub-list proxy settings; reorganized
  Downloads; corrected settings alignment, checkbox and TLS controls.
- Explicit, off-by-default per-hub compatibility for legacy short ADC password
  challenges, with a warning and strict validation retained for other hubs.
- Visual BBCode composing in hub/private inputs, including complete supported
  typed/pasted markup, formatting, history and undo/redo. Unknown/incomplete tags
  remain literal; previews do not fetch remote content.
- Current Qt/core translation catalogs and expanded quit/update diagnostics.

## Installer Fixtures And Local Installation

Six current-object full-application cases passed, three per CPU: normal quit,
canceled quit and forced exit before commit. Normal quit replaced a disposable
signed fixture only after checked GUI/core completion; the other outcomes
retained the old fixture. Helper disappearance, exact tree, signature, protected
canaries and no relaunch were checked after each case.

Fixtures used unique test bundle IDs, unique defaults domains and ephemeral keys.
Some helper caches used fresh UUID namespaces under the real user's cache root;
HOME alone was not complete isolation. No fixture used the live application's
identity/profile. The initially proposed same-ID transaction was held and never
executed because of that namespace risk. Exact release verification plus these
unique-ID fixtures is not same-ID real update/recovery acceptance. No VM is
required by the release plan.

The tested application was subsequently installed on the maintainer's Mac after
normal quit, with app/profile backups retained. Installed executable/plist
fingerprints match the accepted pre.3 installation. This manual installation is
not an automatic same-ID Sparkle replacement/recovery test.

## Public Delivery And Feeds

All eight published assets were downloaded anonymously over bounded, retry-free
HTTPS and matched their qualified SHA-256 digests and byte lengths: two ZIPs,
two checksum sidecars, project source, dependency sources, manifest and SHA256SUMS.
Public ZIPs passed independent authentication and both production-object
verifiers, including their negative controls. Authenticated draft delivery was
checked earlier and is not substituted for these anonymous public downloads.

The CPU-specific feeds and manifest were activated last in commit
`9676ca58b4f0f9e7de2629ee04926fc47560873c` on the public default/feed branch
`codex-2.5.2-release`. Public branch and immutable commit URLs matched the signed
inputs exactly; both feeds passed independent signature/metadata/build-order
checks. Previous feed preimages were retained for a non-forced rollback commit
if needed; no rollback was performed.

The installed build30000010 then completed one manual Preview-channel Check Now
and reported no newer compatible version. No update download/install was
requested. Neither this UI observation nor anonymous curl downloads establish
packet-level product proxy/DNS routing or a real replacement/recovery transaction.

## Materials And Retained Limits

The supplied project archive matches all 3,897 source members at the application
commit. Dependency materials passed all 7,546 payload-member checks plus the
embedded manifest. Closure mappings cover 88 ARM and 44 Intel dependencies,
excluding the separately pinned main executable. Selected libtorrent sources,
provider/link receipts, consumed static inputs and application header overlays
are retained with their distinct provenance. Current Lucide ISC/Feather MIT and
modified Qt Cocoa notices accompany the existing component notices.

Exact consumed OpenSSL 3.4.1 headers and provenance are supplied; its full upstream
archive was not locally retained/verified. This does not imply an ARM 3.4.1 runtime
library: runtime package mappings remain OpenSSL 3.6.3. Dependency section/source
mapping is not bit-for-bit whole-build reproducibility, exhaustive source
completeness or legal certification.

Retained failures include private probe link/dyld preparation errors, fixture
adapter cleanup errors, runner controls and native color-panel automation.
Corrections and later successful results do not erase those records or establish
a causal fix for unrelated failures. Builds/runs were serial on macOS 27; Intel
ran under Rosetta, not a physical Intel or native minimum-OS system.

Still open: the historical intermittent checked-shutdown refusal; same-ID real
replacement/recovery; packet-level product update routing; physical Intel and
native minimum-OS acceptance; native NSColorPanel automation; native-speaker
translation review; broader Windows/Linux qualification; further dependency
reproducibility/provenance work; Developer ID signing and notarization.

Post-release test-only evidence capture is described in
[Development Status](../wiki/Development-Status.md). It changes neither release
bytes nor production shutdown behavior and does not identify the original failure.
